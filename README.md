# homebrew-tap

Homebrew tap for my Mac apps.

## AIWorkstation

**[AIWorkstation](https://github.com/sbaruwal/AIWorkstation)** — a native macOS
canvas for running multiple AI coding agents (Claude Code & Codex) as real terminal cards.

```sh
brew install --cask sbaruwal/tap/aiworkstation
```

## Orbvane

**[Orbvane](https://github.com/sbaruwal/orbvane)** — a native code editor for Mac, written in Rust
(Apple Silicon, macOS 14+).

```sh
brew install --cask sbaruwal/tap/orbvane
```
